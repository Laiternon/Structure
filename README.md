# Anime Builder — мод для Minecraft Forge 1.20.1 (47.2.0+)

Чертёж аниме-построек: окно выбора, 3D-предпросмотр в GUI, призрак постройки в мире и автопостройка
из ресурсов инвентаря и сундуков/бочек/шалкеров в радиусе 16 блоков.

## Как собрать
1. Скачайте официальный Forge MDK 1.20.1 (files.minecraftforge.net) и скопируйте из него
   `gradlew`, `gradlew.bat` и папку `gradle/` в корень этого проекта (обёртка Gradle здесь не включена).
2. JDK 17. Выполните: `./gradlew build` (Windows: `gradlew.bat build`).
3. Готовый мод: `build/libs/animebuilder-1.0.0.jar` → положить в папку `mods`.
   Для запуска из среды разработки: `./gradlew runClient`.
4. Мод нужен и на сервере, и на клиенте.

## Как пользоваться
- Крафт чертежа: книга + лазурит + бумага (бесшапочный рецепт). Также есть во вкладке творчества «Anime Builder».
- ПКМ с чертежом — окно: слева категории (< >) и список построек, по центру 3D-предпросмотр
  (тяните мышью — вращать, колесо — масштаб), справа список материалов «есть/нужно».
- «Предпросмотр в мире» — призрак следует за прицелом.
  R — повернуть, Z — зафиксировать/освободить, B — построить, X — отмена (клавиши меняются в настройках).
  Зелёный оттенок — ресурсов хватает, красный — нет.
- «Построить здесь» — строит в точке, на которую вы смотрели при открытии окна.
- В творческом режиме ресурсы не расходуются. Постройка идёт постепенно (48 блоков/тик).
- Пол постройки (слой y=0) встаёт вровень с блоком, на который вы навели прицел.

## Каталог (23 постройки, 5 категорий)
Деревня ниндзя: дом, башня Хокаге, лавка рамэна, додзё.
Волшебные сказки: купальня духов, дом в дереве лесного духа, пекарня юной ведьмы, коттедж мага.
Фэнтези и гильдии: зал гильдии магов, таверна, замок Повелителя демонов, башня парящего замка, академия магии.
Лаборатории и кузницы: лаборатория гаджетов, мастерская алхимика, кузница мастера мечей, лаборатория науки, ангар мехов.
Повседневная жизнь: школа, святилище, рёкан с онсэном, тематическое кафе.

## Добавить свою постройку
Откройте `catalog/*Pack.java`: постройки описываются мини-DSL (`B`: fill, walls, shell, cylinder, sphere,
roofX/roofZ, pyramid, door, bed, ladder) и регистрируются в `register()` через `Catalog.register(...)`.

## Известные ограничения
- Проект написан без доступа к Minecraft/Forge в среде разработки и НЕ компилировался: возможны мелкие
  ошибки API, которые покажет первая сборка.
- Внешний вид построек и тонкая настройка освещения в GUI-превью требуют проверки в игре.
- Существующие блоки заменяются без выпадения предметов; сундуки и защищённые блоки пропускаются.

## Сборка .jar без установки чего-либо (GitHub Actions)
1. Создайте репозиторий на github.com и загрузите в него содержимое папки проекта (вместе с `.github`).
2. Вкладка Actions → «Build mod» → Run workflow (или просто сделайте commit).
3. Когда сборка закончится, скачайте артефакт `animebuilder-jar` — внутри `animebuilder-1.0.0.jar`.
4. Положите .jar в папку `mods` версии Forge 1.20.1 (в TLauncher должна быть установлена версия «Forge 1.20.1»).
